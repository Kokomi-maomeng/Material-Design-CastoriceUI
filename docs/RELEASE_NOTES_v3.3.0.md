# CastoriceUI v3.3.0

## 修复与真实性

- 订阅初始化不再只校验 HTTPS 字符串后永久显示“需检查”；服务器会分别实际验证本次输入地址和受保护订阅记录的 TLS、公共地址、非空响应与大小边界。输入地址只使用一次且不持久化，运行失败会接入告警中心。
- 初始化向导不再无条件显示“配置已验证”。保存失败会停留在参数步骤；保存后的运行异常会显示实际状态摘要。
- Hysteria2 支持在向导中配置“管理账号=协议身份”映射。唯一管理账号明确拥有全部实时身份时使用统一持久化账本；其他情况保留协议核心计数和未归属差额。
- 账号状态、在线连接和订阅管理分别使用“管理账号”“协议账号”“关联管理账号”，消除 `primary` 与 `user` 含义混淆。
- 流量账号排行按用量降序，未归属用量大于账号用量时会正确排在第一；移除“趋势采样 / 时间桶”卡片并重排为三张摘要卡。
- 网络目标趋势图采用与主流量图一致的响应式宽度测量、坐标网格和指针检查器，修复 2K 宽屏卡片内的缩放与留白问题。
- 右上角时钟改为访问客户端当前时间；流量额度新增独立重置时间，并在计费时区内计算周期边界。

## 安全边界

- 完整订阅 URL、Token、协议 API Secret 仍不写入浏览器响应或审计记录。
- 订阅探测禁止重定向和私有/保留地址解析，并限制响应为 256 KiB。
- 发布仍要求源码、历史、Git 元数据、发布资产和 fresh clone 敏感信息扫描。
