# CastoriceUI v3.4.0

## 新用户与部署可靠性

- 默认自动选择具有真实计数器的默认路由网卡；显式网卡失效时回退到实际检测接口并显示配置告警，不再因示例中的 `eth0` 让仪表盘无限加载。
- 首次实时采集失败返回明确的 `503 dashboard_unavailable`，前端显示可重试错误页，不显示伪造零值。
- Vite 开发服务器提供回环 HTTPS 和 `/api/` 代理，保留 Secure Cookie，并拒绝非回环开发代理目标。
- Nginx SPA 入口补齐因 `add_header` 继承规则而丢失的 CSP、点击劫持、内容类型、权限和来源策略响应头。
- Release 包完整包含 README 引用的桌面宣传图、移动端图片和贡献文档；源码与预构建包的部署路径继续分开说明。

## 数据真实性与配置校验

- 协议和多账号核心计数不再按网卡账本同比例放大或缩小。只在账本更大时增加真实的“未归属”差额，并分别返回统一账本、协议计数总和与账号计数总和。
- `protocol_adapters` 严格验证 `inboundTags` 的列表类型、长度、空值、重复和跨协议冲突，并限制 VLESS `securityProfile` 为受支持值。
- 未配置的 Hysteria2/sing-box 不再生成离线服务卡或严重告警；sing-box 使用正确名称。适配器实际响应但 systemd 单元名称非标准时显示“需关注”，而不是虚报服务停止。

## 安全与维护

- 订阅和远程登录背景请求只连接到已验证的公网 DNS 地址，同时保留原始 Host 与 TLS SNI，关闭 DNS 重绑定的二次解析时间窗。
- 后台请求 User-Agent 自动使用当前后端版本。
- CodeQL init/analyze 固定到同一个动作版本，Dependabot 将 CodeQL 动作作为一个原子组更新，避免拆分 PR 自相冲突。
- 发布前继续要求完整测试、依赖审计、源码/历史/资产/元数据敏感信息扫描、发布包校验和 fresh-clone 验证。
