# CastoriceUI v3.5.0

## 流量分析

- 新增当前月份与此前五个自然月的真实流量卡片。后端按配置时区为每个月生成从 1 日到月末的独立边界，前端按时间升序显示，并以六个月中的最大值作为横向条满宽基准。
- 自然月统计只累计同一月份、同一网卡与同一启动实例内的相邻计数器增量，不跨月、跨网卡、跨重启相减；`sum` 与 `max` 计数模式继续与总流量设置一致。
- 月流量卡片和管理账号用量排行均可独立展开或折叠，并在桌面与窄屏布局中保留清晰的日期、比例和 GB 数值。

## 导航与响应式布局

- 主导航和设置中的八项面板开关统一为：告警中心、账号状态、订阅管理、服务状态、网络质量、在线连接、流量分析、操作审计；总览与初始化向导仍保持在最前。
- 升级时会按上述固定顺序规范化已有的面板显示偏好；仅调整顺序，不会重新启用用户此前关闭的面板。
- 手机端移除固定底部导航条，所有页面继续通过顶部菜单打开完整导航，不再遮挡页面底部内容。
- 桌面端新增侧边栏显示/隐藏按钮。隐藏后内容保持原有可用宽度并在窗口中居中，不因释放侧边栏空间而被横向拉伸。
- 设置底部新增“关于详情”，显示 GitHub 项目主页、作者、项目名和当前版本。

## 文档与发布图

- README 主预览图改为真实 v3.5 页面截图：桌面区域由左下到右上的斜线分隔浅色与深色主题，并使用浅色真实手机页面。
- README 移除独立的“移动端导航（390 × 844）”区块及旧图片引用，并按要求精简截图与协议说明文字。
- 发布包、前后端版本、部署手册和集成文档统一更新为 v3.5.0。

## 升级说明

保留 `/etc/castoriceui/config.json`、完整 SQLite 状态文件、登录背景和现有前后端发布目录。使用版本化目录部署并原子切换，只重启 `castoriceui-backend`；不要因为本次升级重启 Hysteria2、sing-box 或 VPS。部署后验证六个自然月边界、折叠状态、桌面侧栏、手机菜单、登录/退出、数据库完整性、Nginx 与代理进程连续性。
