# CastoriceUI v5.3.0

登录背景和设置体验优化。

- 默认 Material 背景使用卡片，隐藏液态玻璃选项。图片背景可通过统一的开关按钮启用玻璃，开启才显示透明度滑条；新配置默认关闭，已有显式设置保留。
- 重做玻璃的清晰中心、圆角边缘折射、镜面高光和亮暗自适应文字。透明档降低遮盖和散射，默认及色调档逐级加强；减少透明度/提高对比度偏好使用实心回退。该 Web 实现参考 Apple 材质设计，不等同原生系统渲染。
- 有效缓存直接使用；过期和不缓存访问等待新图成功解码，再在失败时回退旧图。已有图片后不自动重试换图，冷启动失败保留有限重试。
- 服务端返回实际图片年龄，防止浏览器续延旧缓存。随机图库 API 请求附加匿名随机刷新参数，保留返回图片及已识别签名 URL；保留并发、时间、请求次数和传输量保护。
- “背景时间”改为“缓存时间”，“立即刷新”改为“不缓存”。补齐分隔线和分组图标，统一设置条目的最小高度、上下间距和组内标签字体，保留显示模式/色彩各自的视觉样式。

升级沿用版本目录、备份与原子切换。只需重启面板后端；代理核心无需重启。历史记录和用户配置保留。

参考：[Apple Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)、[Materials](https://developer.apple.com/design/human-interface-guidelines/materials)。
