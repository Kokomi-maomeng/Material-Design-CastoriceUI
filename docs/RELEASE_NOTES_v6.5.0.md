# CastoriceUI v6.5.0

## 中文

- 实时连接筛选使用固定布局，长 IP 地址和域名有更多输入空间。两项都可在关键词匹配和精准匹配之间切换。
- 网络质量的目标节点可独立折叠。桌面每列按内容重新排列，窄屏使用单列。
- 服务状态压缩卡片，保留版本、运行时间和异常说明。CPU 与内存图表复用总览的浮卡，支持指针、触屏和键盘查看采样。
- 缩短总览流量图的卡片高度，精简主网卡、网络质量、服务健康度、审计中心和设置中的重复文字。
- 补齐折叠、选择和配置向导的动画。统一明暗配色中的主题角色、图表、键盘焦点和设置预览，并校对中英文文案。

## English

- Live connection filters keep a stable layout and offer wider IP and domain inputs, each with a toggle between keyword and exact matching.
- Network targets collapse independently. Desktop cards reflow within each column, and narrow screens use a single column.
- Service cards are more compact and retain version, uptime, and diagnostic details. The CPU and memory chart shares the overview inspector for pointer, touch, and keyboard input.
- The overview traffic trend is shorter. Redundant copy was removed from overview cards, Audit Center, and Settings.
- Added motion to disclosures, selection controls, and setup steps. Matched theme roles, charts, keyboard focus, and settings previews across light and dark modes and refined Chinese and English copy.

See the [upgrade guide](DEPLOYMENT.md) for package verification and rollback.
