# CastoriceUI v6.6.1

- The sign-in card uses one translucent glass surface with text color adapted to the photo. Sign-in checks start in parallel, and the form shows progress until the console opens.
- Total traffic distribution shows known core counters and the positive remainder from measured interface billing-period usage. The chart shows both totals separately when the core counters exceed the interface usage.
- Live connection filters align the controls and Clear filters. Exact match is part of each address field and keeps its position when toggled.
- Audit log retention uses the existing presets in one labeled dropdown. Existing saved durations are retained until changed.

See [Deployment and recovery](DEPLOYMENT.md) for installation and upgrade instructions.
