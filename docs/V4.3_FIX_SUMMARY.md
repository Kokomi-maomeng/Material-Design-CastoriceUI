# CastoriceUI v4.3.0 问题修复与交叉验证报告

日期：2026-09-15

范围：用户界面一致性、流量分析、输入与登录安全、原子升级、依赖与浏览器契约、发布资料。

## 需求处理结果

1. **统一关闭动画**：对话框、设置、初始化向导、流量额度窗口、抽屉遮罩、选择器、日期选择器、账号菜单、协议详情、折叠卡片和悬浮说明均保留 DOM 至退出动画结束。进入、退出、图标旋转和高度变化统一使用 Material Design 3 的标准缓动，并支持 `prefers-reduced-motion`。
2. **删除账号状态冗余说明**：中英文的“协议核心生命周期累计；面板计费周期额度……”整段文字及其空占位均已删除，全部、账号启用和账号禁用筛选状态一致。
3. **账号状态命名**：`登记启用/登记禁用` 和 `Registered enabled/disabled` 分别改为 `账号启用/账号禁用` 与 `Account enabled/disabled`。
4. **在线连接协议条**：取消右侧独立开关列，整行可点击并支持 Enter/Space；前置图标固定可见并随展开状态旋转。详情区使用可逆高度/透明度动画，横向表格滚动不会再影响开关可达性。
5. **流量分析布局与协议分布**：流量趋势独占一行；近期月流量与协议分布移至下一行并保持协议卡片较窄。协议图例支持五行展示；超过五项时第四项后显示“更多协议”，其悬浮卡片支持鼠标、键盘和触屏，能够突出对应圆环分段，并依据视口空间放在卡片左右或上下且限制在屏幕内。
6. **统计覆盖说明**：删除固定占位卡片，改为指标文字右侧的信息图标；鼠标悬停、键盘聚焦或触摸可打开定位式说明卡片，点按其他区域或 Escape 关闭。
7. **展开选项定位**：选择器和日期选择器实时测量触发条、内容与上下可用空间，靠近窗口底部时紧贴条目向上展示；窗口缩放、滚动和极窄/极矮视口下重新定位并限制尺寸。
8. **v4.2 审计问题**：A42-01 至 A42-10 均有代码级处理，详见下表。
9. **M3 视觉一致性**：弹窗、悬浮卡片、折叠内容、图标和遮罩采用相同的 180–240 ms 时序族、强调/标准缓动、圆角和 elevation；减少动态效果偏好下关闭非必要运动。
10. **GitHub 展示图**：移除展示图中的版本号和手机黑色横条；手机使用当前 v4.3 代码在 390 px 视口实际渲染的总览页面，桌面使用同一份流量分析页面的浅色/深色真实渲染做对角拼接。截图仅注入隐私安全的受控示例接口数据，未生成、重画或虚构产品组件。

## 自动检查

- ESLint、TypeScript、Node 静态契约测试、Vitest 组件交互测试、Python 编译与后端单元测试。
- 敏感信息扫描、生产构建、完整及生产依赖 npm audit。
- 发布包内容清单、版本注入、无符号链接、无 Python 缓存和确定性 SHA-256 复建检查。
- 服务器部署阶段另做 shell 语法、只读预检、systemd、Nginx、HTTPS、鉴权、状态持久化和代理进程连续性检查。

## 验证边界

按本次要求未尝试实体 Safari/iPhone/iPad 设备验证。项目只将 Safari/iOS 16.4 写为构建目标和支持契约；自动化测试与代码审查不能替代真实设备、GPU、输入法、DPI 或浏览器渲染验收。
