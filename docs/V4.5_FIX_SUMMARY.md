YAML bodies are limited to 256 KiB, 2048 proxy nodes, 20,000 composition nodes and depth 32. Aliases and custom object tags are intentionally unsupported. Parseable subscription format, HTTPS reachability and actual proxy connectivity remain distinct evidence levels. See [PyYAML's safe-loading documentation](https://pyyaml.org/wiki/PyYAMLDocumentation).

The supported deployment layout keeps config under `/etc/castoriceui` and service-writable data under `/var/lib/castoriceui`. Custom loopback addresses/ports and config filenames use the same values throughout installation. Arbitrary home/data paths are rejected before mutation rather than bypassing systemd protections.
