# v4.6 问题修复与验证范围

| 请求 | 实现 |
| --- | --- |
| 收起侧边栏后左上角出现小条 | 桌面端明确隐藏移动导航遮罩按钮，移动端继续使用原导航遮罩。 |
| 页面、设置及向导的滚动条消失并引起位移 | 根滚动容器始终保留纵向滚动条与空间；弹窗通过输入拦截、背景滚动位置保护及 inert 锁定背景，保持原滚动条；嵌套弹窗正确恢复父层状态；移除设置内部滚动条隐藏样式。 |
| 初始化“接入前检查”卡片文字偏下 | 独立设置对称上下内边距及说明行距，窄屏使用适配内边距。 |
| 操作审计时间不直观 | 使用浏览器本地时区的年月日和时分秒，显示时区名称；保留机器可读原始时间；告警同样处理。 |
| 告警全部记录与审计保持一致 | 两页共用展开、收起及分页组件；最近 30 条、展开每页 50 条、页码与跳页。SQLite 分页遍历全部告警。 |
| 待处理自动消失 | 以未手动确认为待处理条件，与实际恢复分开。恢复时间、确认时间与事件历史完整保留。单条确认使用独立事件身份；全部确认使用数据库事务覆盖所有页面。通知及严重性数量从完整未确认历史统计。 |

告警历史不再按操作审计保留周期删除。升级后既有未确认记录会重新进入待处理；在旧版本中已经删除的记录不能凭空重建。仪表盘仍使用有界历史缓存，分页 API 和待处理数量独立读取完整 SQLite 历史。后台采集 watchdog 保留全部实际活动告警，避免缓存边界导致错误恢复。

回归覆盖恢复后待处理、进程对象重建、同一条件再次发生、确认旧事件、确认幂等、超过 200 条历史、多页全部确认、无效分页、登录及 CSRF、确认失败，以及本地时间格式。浏览器检查覆盖十页面、桌面与窄屏、全部向导、嵌套额度弹窗、下拉框及三个时区。完整检查包括 lint、TypeScript、32 项 Node 契约、42 项前端运行测试、123 项后端测试、敏感内容扫描、构建及依赖审计。

生产升级沿用事务备份与原子目录切换，仅重启面板后端。代理进程连续性、实际部署、GitHub CI 和公开资产校验结果由发布交付记录说明。自动化检查不能证明所有未来配置与浏览器组合均无缺陷。
