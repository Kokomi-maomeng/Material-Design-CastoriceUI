# v5.0.1 rework

| Requirement | Correction / acceptance path |
| --- | --- |
| Existing browser receives the deployed page | Reproduce identical timestamp/length HTML validators with real isolated Nginx; installer disables ETag and If-Modified-Since handling for HTML only. Verify normal reload with old validators. |
| Confirmed offline, unknown and recovered remain distinct | Listener evidence precedes statistics availability; unknown recovery retains its outage episode; core aggregation includes only its dependent protocols. Behavioral tests cover all three. |
| Saved evidence is usable from the UI | Authenticated episode evidence API and dialog show first/worst/latest samples and then-effective thresholds. Missing historical samples are never reconstructed. |
| Hour/day network history | Bounded authenticated queries, separate family selection, 20s/2min/5min granularity, per-bucket RTT/loss maxima, explicit partial buckets/gaps and query limits. 100% loss remains visible without an RTT. |
| Layered and contextual diagnosis | Expand ICMP/TCP/DNS evidence or correlation/official context; unknown source state is explicit. Official status and resource counts are candidate context, without an unsupported cause assertion. |
| All original v5.0 controls remain operable | Browser matrix covers language menus, overflow, autofill, all glass/theme/viewport states, slider/card persistence, background entry/F5/logout/expiry/decode/failure, critical acknowledgements and units. |
| Safe deployment and publication | Versioned backup and atomic switch, protected core PID/config comparison, HTML/public API/real browser verification, identity/privacy gates, CI/CodeQL and anonymous artifact verification. Site-specific evidence belongs outside public source. |

Monitoring still has explicit conditions: a single vantage point cannot represent every user; a shared-password core needs a separately planned authentication migration to gain a dedicated server test identity. Do not restart proxies to claim this condition closed. Existing successful certificate hot-load integration evidence remains applicable only after verifying that the deployed receiver and core builds are unchanged. Natural future renewals and long-term observations remain observations, not completed fault injections. High availability remains a conditional design decision rather than a second node installed by this release.

History retention is bounded by 7d and 180,000 shared monitoring records, so the capacity limit may shorten the available period. Day views return at most 5,000 source rows and report truncation. No samples are invented to fill a missing period.
