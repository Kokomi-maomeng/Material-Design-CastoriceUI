The original disappearance was not reproduced against the production provider. Static inspection found that the old 900s cache returned an error after refresh failure and suppressed retries for 30s, while the page had no decoded-image fallback. Regression fixtures reproduce that failure path; this does not prove the cause of a past incident without its request logs.

Server cache storage is at most eight 30 MB images plus one temporary image (240 MB + 30 MB), next to the configured database in `background-cache`. Responses stream in 64 KiB chunks. The browser keeps one image in memory and at most three image variants in Cache Storage (90 MB). Storage-disabled browsers still work without persistence. A request budget can defer replacement and serve the previous image; it does not claim DDoS protection for the entire hosting stack. No automatic production alert acknowledgement is part of acceptance.

Glass styling follows Apple's [materials guidance](https://developer.apple.com/design/human-interface-guidelines/materials), with opacity/contrast fallbacks and restrained static effects. It is a web approximation, not a claim to reproduce Apple's native optical renderer. CSS behavior is described by [scrollbar-gutter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/scrollbar-gutter) and [backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter).

Run `npm run check` and `python scripts/browser-v50.py` along with the existing browser suites. CI also requires Chromium/Firefox/WebKit, Debian 12/13 Nginx templates, real VM installation/rollback/reboot and CodeQL. Live deployment acceptance and private endpoint evidence remain outside the public source repository; passing source tests alone is not production acceptance or a guarantee for every device.
