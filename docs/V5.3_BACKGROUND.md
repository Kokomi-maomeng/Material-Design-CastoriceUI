# 登录背景与设置（v5.4）

| 要求 | 行为 | 回归入口 |
|---|---|---|
| 默认 Material | 固定卡片，隐藏液态玻璃设置 | v50.runtime、browser-v53 |
| 玻璃开关 | 与其他设置相同的按钮；新配置关闭，开启才出现滑条；保留显式旧配置 | v50.runtime、HTTP 设置往返 |
| 玻璃材质 | 图片按页面布局坐标对齐；无边缘位移或弯曲，保留低散射、高光与明暗前景适配 | browser-v53 的真实像素差异与多尺寸画面 |
| 刷新与缓存 | 有效缓存不请求；到期/不缓存先等新图，失败才回退；显示后不自动换图；冷失败有限重试 | background.runtime、test_v50_background、browser-v50/v53 |
| 文案 | 缓存时间 / 不缓存（Cache duration / No cache） | UI 交互与选择器 |
| 设置节奏 | 四个分组标题图标，补全分隔线，主选项最小 76px/上下16px，背景组标签一致 | browser-v53 computed style |

从 v5.3.1 起，缓存时间仅在刷新或打开页面时判断，不是登录、注销或轮播间隔。应用根组件持有已解码图片；同一页面内登录、注销和调整窗口均复用它，注销不再等待重新读取背景配置。以导航开始时间判断有效期，避免配置响应延迟误判；有效缓存直接复用且不续期，过期或不缓存时重新请求。一次请求完成后可展示的图片，包括失败回退图，客户端缓存从解码完成开始；回退标记保留，不代表上游恢复。旧版无客户端时间的图片只作首次请求失败回退；存储不可用时保留当前页面图片及服务端回退。

随机图库的初始请求添加匿名刷新量，重定向后的图片 URL 保持原样。常见签名 URL 保留查询；返回 404/410 的间接图片可在同一 15 秒/5 跳预算内重选一次。请求次数、并发、失败退避及传输量限制继续有效。图库本身不可用、随机命中已删图片或达到保护限制时允许显示上一张；不承诺第三方每次提供不同且可用的图片。

玻璃参考 [Apple 的材质原则](https://developer.apple.com/design/human-interface-guidelines/materials) 和 [Liquid Glass 介绍](https://developer.apple.com/videos/play/wwdc2025/219/)。v5.4 移除静态位移贴图与边缘折射，保留 SVG 模糊、色调、边缘高光及明暗前景适配；指针仅改变镜面高光位置，没有持续渲染循环。减少透明度/提高对比度时回退实心材质，减少动态效果时不跟随指针。它不是 Apple 原生材质实现或物理 Apple 设备验收。

v5.4 的滑块拖动连续跟手，松手后吸附到透明/默认/色调三档；方向键每次切换一档。新配置依然选择默认档且关闭玻璃。背景来源切换前未保存的 API 与服务器图片各自保留草稿；保存后当前文档立即采用返回的外观配置，下一次注销无需刷新。纯玻璃或缩放修改复用原图，不触发图库刷新。启动时背景读取与会话验证并行，验证完成前保持启动画面；图库速度及原图大小仍影响新图等待，缓存策略保持原样。

设置统一仅作用于设置对话框的行和同一组标签；显示模式预览、主题色板保留各自样式。旧主版本的全部页面、记录/图表和部署矩阵继续作为回归门禁。
